PACKAGE DETAILS

What does each package actually mean?

We've kept the packages deliberately straightforward so you can choose based on what you actually need from us after your website launches.

OPTION 01

Website Hosting

£9.99 / month

Best suited to businesses that don't expect to need regular changes after launch and simply want Elero to look after the technical hosting of the finished website.

What's included

  • Hosting of your Elero website
  • Secure HTTPS connection
  • Website availability monitoring
  • Initial SEO setup at launch
  • Technical hosting management
  • 30 days of reasonable post-launch edits

What isn't included

Once the initial 30-day post-launch period has ended, ongoing content amendments, image changes, new pages, redesign work and new functionality are not included in the Hosting package.

If you regularly want Elero to make changes for you, the Managed Website package is the better fit.

OPTION 02

Managed Website

£49.99 / month

Best suited to businesses that want to leave the ongoing management of their website to us rather than dealing with website changes themselves.

Everything in Website Hosting, plus:

  • Routine text amendments
  • Replacing existing images
  • Updating opening hours
  • Updating prices
  • Updating service information
  • Changing contact information
  • Updating staff / team information
  • Adding or changing testimonials
  • Updating existing website sections
  • Existing form amendments
  • Small content and layout adjustments
  • Ongoing technical SEO upkeep

What counts as a routine amendment?

A routine amendment is a change to the existing website rather than the creation of something substantially new.

For example, changing your prices, replacing photographs, updating a service description or changing your opening hours would normally fall within the Managed Website package.

What isn't included

Entirely new pages, major redesigns, substantial new sections, new booking systems, new calculators, portals, dashboards or other significant new functionality would be treated as new development and quoted separately before work begins.

OPTION 03

Website & Business Systems

£349 / month

Designed for businesses using Elero-built software that forms part of their day-to-day operation — not just a standard marketing website.

Everything in Managed Website, plus:

  • Custom software hosting
  • Database management
  • Database backups where appropriate
  • System availability monitoring
  • Error monitoring
  • Bug fixes to existing Elero-built systems
  • Booking system maintenance
  • Portal maintenance
  • Dashboard maintenance
  • Calculator / interactive-tool maintenance
  • Existing API and integration maintenance
  • Automated email maintenance
  • Notification-system maintenance
  • Login and authentication-system maintenance
  • Existing customer journey monitoring
  • Existing enquiry journey monitoring
  • Routine system adjustments
  • Minor workflow improvements
  • Security maintenance for Elero-built systems
  • Performance monitoring
  • System health reviews
  • Priority technical support

What kind of businesses is this for?

This package is intended for businesses using more advanced Elero-built functionality such as candidate portals, staff systems, booking platforms, customer accounts, sales pipelines, property lead systems, databases, automated workflows or similar custom software.

What's the difference between maintenance and new development?

Maintaining, fixing or making routine adjustments to the existing system is included.

Building a substantial new feature, an entirely new module, a major redesign or a separate software system is new development and would be quoted separately before any work begins.

GOOD TO KNOW

Keeping the packages straightforward.

We want you to know what you're paying for before you choose a package.

NEW DEVELOPMENT

New functionality is quoted separately.

New pages, substantial redesigns, new systems and major new functionality fall outside normal website or system maintenance. We will always agree a price before carrying out additional project work.

THIRD-PARTY SERVICES

External service charges aren't included.

Charges from third-party providers such as payment processors, specialist APIs, messaging platforms or other external software remain separate unless specifically stated otherwise.

SEO

Initial SEO is not ongoing SEO marketing.

Every website receives initial SEO foundations. Active ongoing SEO campaigns, content strategies and sustained search-ranking work are separate services where required.
