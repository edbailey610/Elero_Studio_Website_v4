ELERO STUDIO WEBSITE — V5 SEO

Changes:
- Improved Google title and meta description
- Added canonical URL
- Added WebSite + Organization structured data
- Added branded favicon
- Added social sharing preview
- Prevented header/call/footer boilerplate from being used in Google snippets
- Added robots.txt and sitemap.xml

Deploy:
Copy all files into the existing Elero GitHub repo, replacing the current files.
Then GitHub Desktop -> Commit -> Push.
Netlify will update elerostudio.com automatically.

After deploy:
Use Google Search Console -> URL Inspection -> https://elerostudio.com/ -> Request indexing.
Also submit https://elerostudio.com/sitemap.xml in Search Console -> Sitemaps.

Google may take several days or longer to refresh the search result.
